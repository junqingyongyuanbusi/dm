## 与完整原型仍有差距

**这是一版本地可验收实现，不是全部功能 1:1 完成声明。**

1. 流程页展示现有受控决策链，并链接真实 Agent 配置；尚无原型的任意拖拽节点、
   流程保存／发布及独立运行统计引擎。
2. 测试台进入现有 Prompt 试答，不是完整 RAG／渠道约束重放；本地采用 stub，
   尚未验收真实模型、真实平台凭证和外发。
3. 工作空间设置仍以现有配置入口为主，尚未实现原型全部营业时间、通知和保留期持久化。
   成员页面没有完整团队组织模型；运营回复／接管开关目前按成员配置，而非全局开关。
4. 旧草稿审核和投递异常保留原工作区，尚未统一为新三栏；会话历史有界展示最新 100 条。
   标签、备注、优先级、稍后处理等原型交互没有全部新增持久化闭环。
5. 金融指南只是安全模板；真实资料仍需业务方核验。内部 SOP 的独立受众隔离模型未实现，
   不能把内部资料发布到客户 RAG。知识来源和核验日期目前不是独立数据库治理字段。
6. WhatsApp／Feishu 新接入继续限管理员，账号 owner 的任意断开等操作未按演示放宽；
   后端安全约束优先于演示。权限变更后的完整生产并发验收与兼容发布方案仍未完成。

生产发布在 `docs/production-migration.md` 中明确处于阻塞状态；不能直接运行通用发布脚本
